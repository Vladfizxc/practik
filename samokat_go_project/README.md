# Самокат GO — учебный проект
Откройте `index.html` в браузере. Использованы HTML5, CSS3 и JavaScript.
Реализованы разделы сайта, адаптивное меню, каталог моделей, тарифы, выбор модели/тарифа и проверка демонстрационной формы.
Ограничения: нет сервера, БД, онлайн-оплаты, геолокации и реальной передачи заявок. Контакты, цены и характеристики условные.
